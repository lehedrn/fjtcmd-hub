## 输入方式

### 1. 配置文件（generator.yml）

```yaml
# 全局配置
author: ztq
packageName: com.ruoyi.system
tplWebType: element-plus-typescript   # js 或 typescript
autoRemovePre: false
tablePrefix: fjtcmd_
output: /path/to/output               # 生成代码输出目录
template: crud                        # crud | tree | sub
formColNum: 1                         # 1/2/3
genView: false                        # 是否生成详情页
```

### 2. 表结构文件（两种方式）

**方式 A：直接传入 CREATE TABLE SQL**

```sql
CREATE TABLE fjtcmd_product (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  product_name VARCHAR(200) COMMENT '商品名称',
  price DECIMAL(10,2) COMMENT '价格（元）',
  stock INT COMMENT '库存数量',
  status TINYINT DEFAULT 0 COMMENT '状态（0下架 1上架）',
  image VARCHAR(500) COMMENT '商品图片',
  description TEXT COMMENT '商品描述',
  create_by VARCHAR(64) DEFAULT '',
  create_time DATETIME,
  update_by VARCHAR(64) DEFAULT '',
  update_time DATETIME,
  remark VARCHAR(500)
) COMMENT='商品信息表';
```

CLI 内部用 Druid SQL Parser 解析 CREATE TABLE 语句，自动推断列类型、注释等信息。

**方式 B：YAML 描述表结构**（不依赖数据库时更灵活）

```yaml
table:
  name: fjtcmd_product
  comment: 商品信息表
  className: Product           # 可选，不填则自动从表名推断
  columns:
    - name: product_name
      comment: 商品名称
      type: varchar(200)
      isList: true
      isQuery: true
    - name: price
      comment: 价格（元）
      type: decimal(10,2)
      isList: true
    - name: stock
      comment: 库存数量
      type: int
      isList: true
    - name: status
      comment: 状态
      type: tinyint
      isList: true
      htmlType: radio
      dictType: sys_normal_disable
    - name: image
      comment: 商品图片
      type: varchar(500)
      htmlType: imageUpload
    - name: description
      comment: 商品描述
      type: text
      htmlType: editor
```

### 3. 命令行使用

```bash
# 从 CREATE TABLE SQL 生成
java -jar ruoyi-generator-cli.jar \
  --config config/generator.yml \
  --sql sql/create_product.sql \
  --output ./generated

# 从 YAML 表结构生成
java -jar ruoyi-generator-cli.jar \
  --config config/generator.yml \
  --table-config sql/product_table.yml \
  --output ./generated

# 预览模式（输出到 stdout 不写文件）
java -jar ruoyi-generator-cli.jar \
  --config config/generator.yml \

  --preview
```

## 关键实现点

1. **SQL 解析**：复用项目中已有的 Druid SQL Parser，从 CREATE TABLE 中提取列名、类型、注释、主键、自增等信息
2. **字段推断**：复用 `GenUtils.initColumnField()` 逻辑，自动推断 javaType、htmlType、queryType
3. **Velocity 渲染**：复用 `VelocityUtils.prepareContext()` 和 22 个 .vm 模板，完全不用改
4. **文件输出**：复用 `VelocityUtils.getFileName()` 计算输出路径，直接写入文件系统
5. **依赖精简**：只需要 `velocity-engine-core` + `druid-spring-boot-4-starter`（仅用于 SQL Parser）+ YAML 解析库
