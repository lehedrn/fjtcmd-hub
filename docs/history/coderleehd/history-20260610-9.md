## 关键占位符说明

| 占位符 | 说明 | 示例 |
|--------|------|------|
| `${moduleName}` | 模块名 | demo |
| `${mainBusinessName}` | 主表业务名 | customer |
| `${mainClassName}` | 主表类名 | Customer |
| `${mainTableName}` | 主表中文名 | 客户 |
| `${mainPkColumn.javaField}` | 主表主键字段 | customerId |
| `${mainNameColumn.javaField}` | 主表名称字段 | customerName |
| `${mainPermissionPrefix}` | 主表权限前缀 | demo:customer |
| `${subBusinessName}` | 子表业务名 | goods |
| `${subClassName}` | 子表类名 | Goods |
| `${subFunctionName}` | 子表功能名 | 商品 |
| `${subRoute}` | 子表路由 | customer-goods |
| `${subTableFkName}` | 外键列名 | customer_id |
| `${subTableFkJavaField}` | 外键Java字段 | customerId |

这样所有动态部分都通过占位符抽象出来了，符合模板化的要求。

### 六、角色权限分配

生成的菜单需要分配给角色，这部分有两种方案：

#### 方案A：手动分配（推荐）
- 生成菜单后，由管理员在系统后台手动分配给角色
- 优点：灵活可控
- 缺点：需要额外操作

#### 方案B：自动分配
- 在菜单 SQL 中自动插入角色菜单关联
- 需要指定默认分配的角色ID
- 优点：自动化
- 缺点：不够灵活

```velocity
#if($autoAssignRole)
-- 自动分配给指定角色
#foreach($roleId in $roleIds)
INSERT INTO sys_role_menu (role_id, menu_id) VALUES 
($roleId, @mainMenuId),
($roleId, @mainMenuId + 1),
-- ... 所有按钮权限
#end
#end
```

### 八、菜单生成的注意事项

1. **菜单ID获取**：使用 `LAST_INSERT_ID()` 获取刚插入的菜单ID
2. **父菜单ID**：子表权限的 parent_id 使用主表菜单ID（@mainMenuId）
3. **排序号**：主表按钮 1-5，子表按钮 6-11
4. **菜单类型**：
   - 主表：`C`（菜单）
   - 按钮：`F`（按钮）
5. **显示状态**：所有按钮都是 `visible='0'`（显示）
6. **权限标识**：遵循 `模块:主表:操作` 和 `模块:主表:子表:操作` 的格式
