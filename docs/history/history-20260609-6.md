## 详情页功能支撑分析

### 当前 generator 模块 ✅ 完全支持

详情页是**当前版本新增**的功能，generator 模块已包含完整支撑：

| 组件 | 状态 | 说明 |
|------|------|------|
| `view.vue.vm` 模板 | ✅ 有 3 份 | `vue/view.vue.vm`、`v3/view.vue.vm`、`v3ts/view.vue.vm` |
| `GenTable.isView` 字段 | ✅ 有 | boolean 类型 |
| `GenConstants.GEN_VIEW` | ✅ 有 | 常量值 `"genView"` |
| `VelocityUtils.genView()` | ✅ 有 | 从 `options` JSON 读取 `genView` 布尔值 |
| `getTemplateList()` 逻辑 | ✅ 有 | `if (isView) templates.add(useWebType + "/view.vue.vm")` |
| 模板内容 | ✅ | 生成 `el-drawer` 形式的详情页，展示所有列表字段 |

详情页的触发机制：`GenTable.options` JSON 中包含 `{"genView": true}` 时，模板列表会自动加入 `view.vue.vm`。

### 参考项目 ❌ 不支持

参考项目是旧版本创作的：
- 没有 `view.vue.vm` 模板
- 没有 `isView` / `GEN_VIEW` 
- `buildOptions()` 只处理 `parentMenuId` 和树表字段，没有 `genView`

### 重构后的补全方案（~10 行代码）

在参考项目的基础上补上 `genView` 支持，涉及 3 处小改动：

```java
// 1. GenCliConfig.GlobalConfig 添加字段
private Boolean genView;

// 2. GenCliConfig.TableConfig 添加字段  
private Boolean genView;

// 3. ConfigLoader.buildOptions() 添加处理
Boolean genView = (tc != null && tc.getGenView() != null) ? tc.getGenView()
                 : (g != null && g.getGenView() != null) ? g.getGenView()
                 : null;
if (genView != null) {
    options.put(GenConstants.GEN_VIEW, genView);
}
```

YAML 配置示例：
```yaml
global:
  genView: true     # 全局默认开启详情页

tables:
  sys_student:
    genView: false  # 某张表可单独关闭
```
