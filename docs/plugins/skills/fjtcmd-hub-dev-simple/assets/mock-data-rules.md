# 模拟数据生成规则

生成模拟数据时遵循以下规则。

---

## 数据量

| 类型 | 数量 |
|------|------|
| 单表 | 20 条 |
| 树表 | 20 条（层级合理分布） |
| 主子表 | 主表 20 条 + 每条主表 20 条子表（共 420 条） |

## 字段生成规则

### 文本字段
- 姓名：使用中文姓名（张伟、李娜、王芳、刘洋等）
- 标题：使用有意义的中文标题
- 备注：生成简短的中文描述
- 手机号：`1` + `3-9` + 9 位随机数字
- 邮箱：`{name}@example.com`

### 数值字段
- 年龄：18-60 随机
- 价格：10.00-9999.99 随机
- 数量/库存：0-1000 随机
- 排序：1-100 递增

### 字典字段
- 均匀覆盖所有字典选项
- 状态类：80% 正常(0) + 20% 其他(1)
- 性别类：均匀分布（男/女/未知）
- 类型类：均匀分布

### 时间字段
- 范围：近 1 年内随机时间
- 格式：`YYYY-MM-DD HH:MM:SS`
- 创建时间：分散在不同日期
- 更新时间：晚于创建时间

### 外键字段（主子表）
- 严格对应主表 ID
- 子表的 `{主表}_id` 必须引用已插入的主表记录

### 树表字段
- `parent_id`：保证层级合理
  - 一级节点：3-5 个，`parent_id = 0`
  - 二级节点：每个一级下 2-4 个
  - 三级节点：少量
- `ancestors`：正确记录祖级路径（如 `0,1,5`）

## SQL 格式

```sql
-- {模块名称} 模拟数据（{数量}条）
-- 生成时间：{日期}

INSERT INTO {table_name} ({字段列表}) VALUES
({值1}),
({值2}),
...
({值N});
```

## 注意事项

- 不包含 id 字段（使用 AUTO_INCREMENT）
- 不包含审计字段（create_time/update_time 使用 DEFAULT）
- 使用 `docker exec` 执行时加 `--default-character-set=utf8mb4`
- 使用 `db_executor.py exec --file` 执行，自动处理字符集
