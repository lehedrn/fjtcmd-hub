## 各模板详细说明

### 1️⃣ 标准模板（CRUD/Tree/Sub）

**适用场景**：
- ✅ 单表数据维护（学生管理、商品管理）
- ✅ 树形结构数据（部门管理、分类管理）
- ✅ 主子表结构（订单 + 订单明细）
- ✅ 无复杂业务流程

**文档内容**：
1. 需求概述
2. 表结构 (DDL)
3. 代码生成配置 (YAML)
4. 字典设计 + SQL 脚本
5. 功能清单 + 权限标识

**交付物**：
- DDL SQL 脚本
- fjtcmd-hub-generator-cli YAML 配置
- 字典数据 SQL
- 菜单 SQL（可选）

**代码生成命令**：
```bash
# Web 版代码生成
访问 http://localhost:18081/tool/gen

# CLI 代码生成
java -jar fjtcmd-hub-generator-cli/target/fjtcmd-hub-generator-cli.jar \
  --config config.yaml \
  --sql schema.sql
```

---

### 2️⃣ 简单业务模板

**适用场景**：
- ✅ 标准 CRUD + 简单业务规则
- ✅ 少量自定义接口（审核、激活、分配）
- ✅ 简单业务流程（无需工作流引擎）
- ✅ 需要数据权限控制

**文档内容**：
1. 需求概述
2. 表结构 (DDL)
3. 业务规则（校验/状态流转）
4. 自定义接口
5. 功能清单

**交付物**：
- DDL SQL 脚本
- 业务规则说明
- 自定义接口定义
- Service 层逻辑代码

## 快速选择表

| 需求特征 | 推荐模板 | 示例 |
|---------|---------|------|
| 纯数据维护，无业务规则 | 标准模板 | 学生管理、商品管理 |
| 树形结构数据 | 标准模板 | 部门管理、分类管理 |
| 主子表结构 | 标准模板 | 订单 + 订单明细 |
| 有简单状态校验 | 简单业务模板 | 文章发布（草稿/发布） |
| 有简单审核流程 | 简单业务模板 | 请假申请（一级审批） |
| 有数据权限控制 | 简单业务模板 | 部门数据隔离 |

---

## 模板降级原则

**从高复杂度模板降级到低复杂度模板是允许的**：

- 简单业务模板 → 标准模板：如果业务规则简化，可降级

**从低复杂度模板升级到高复杂度模板需要评估**：

- 标准模板 → 简单业务模板：添加业务规则时需要补充文档
