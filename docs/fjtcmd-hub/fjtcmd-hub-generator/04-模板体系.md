## 4.2 模板类型说明

### 后端模板类型（tplCategory）

| 类型 | 常量值 | 说明 | 特点 |
|------|--------|------|------|
| **单表** | `crud` | 增删改查单表 | 最常见，分页列表 + 标准 CRUD |
| **树表** | `tree` | 树形结构增删改查 | el-table 带 tree-props，支持展开/折叠、树形下拉选择父节点、不分页 |
| **主子表** | `sub` | 主表+子表联动 | 生成两份 domain（主表+子表），新增/修改时内嵌可编辑子表表格，事务控制 |

### 前端模板类型（tplWebType）

| 类型 | 说明 | 模板目录 | Script 标签 |
|------|------|----------|------------|
| `element-plus` | Vue 3 + JavaScript | `vm/vue/v3/` | `<script setup>` |
| `element-plus-typescript` | Vue 3 + TypeScript | `vm/vue/v3ts/` | `<script setup lang="ts">` |

### TypeScript 版与 JS 版的差异

| 方面 | JS 版 | TS 版 |
|------|-------|-------|
| 模板目录 | `vm/vue/v3/` | `vm/vue/v3ts/` |
| API 文件 | `js/api.js.vm` → `.js` | `ts/api.ts.vm` → `.ts`，带完整泛型签名 |
| 类型定义 | 无 | `ts/type.ts.vm` → 生成 QueryParams 和 Data 接口 |
| 变量声明 | `ref([])` | `ref<${ClassName}[]>([])` |
| 函数参数 | 无类型 | 带类型注解，如 `handleUpdate(row: ${ClassName})` |
| 表单数据 | `form: {}` | `form: {} as ${ClassName}` |
| 主键处理 | 不区分类型 | 根据 javaType 区分 `number` / `string` |

### TS 类型推断映射

| Java 类型 | TS 类型 |
|-----------|---------|
| `String` | `string` |
| `Long` / `Integer` | `number` |
| `Boolean` | `boolean` |
| `Date` | `string`（前端以字符串传输） |
| `BigDecimal` | `string`（保持精度） |

## 4.3 模板选择逻辑

`VelocityUtils.getTemplateList(table)` 根据 `tplCategory` + `tplWebType` 动态决定渲染哪些模板：

```
基础模板（所有模式都有）:
  └── domain.java.vm, mapper.java.vm, service.java.vm, serviceImpl.java.vm,
      controller.java.vm, mapper.xml.vm, sql.vm

API 模板:
  ├── element-plus          → js/api.js.vm
  └── element-plus-typescript → ts/api.ts.vm

TypeScript 专属（仅 element-plus-typescript）:
  └── type.ts.vm, index.ts.vm

前端页面模板:
  ├── tplCategory=crud → index.vue.vm
  ├── tplCategory=tree → index-tree.vue.vm
  └── tplCategory=sub  → index.vue.vm + sub-domain.java.vm

详情页（genView=true）:
  └── view.vue.vm

模板路径前缀:
  ├── element-plus           → vm/vue/v3/
  ├── element-plus-typescript → vm/vue/v3ts/
  └── 其他                    → vm/vue/
```

## 4.4 VelocityInitializer 初始化

```java
public static void initVelocity() {
    Properties p = new Properties();
    p.setProperty("resource.loader.file.class",
        "org.apache.velocity.runtime.resource.loader.ClasspathResourceLoader");
    p.setProperty(Velocity.INPUT_ENCODING, "UTF-8");
    Velocity.init(p);
}
```

- 使用 **ClasspathResourceLoader**，从 classpath 加载 `.vm` 模板
- 编码固定为 **UTF-8**
- 每次生成代码前都会调用（幂等操作）

## 4.9 文件上传接口对接

代码生成器中涉及的 `htmlType=imageUpload`（图片上传）和 `htmlType=fileUpload`（文件上传）字段，**不需要额外生成后端接口**，项目已有通用文件上传能力。

### 后端已有通用接口

**Controller**：`CommonController.java`（`fjtcmd-hub-admin` 模块）

| HTTP | 端点 | 说明 |
|------|------|------|
| `POST` | `/common/upload` | 单文件上传，返回 `{url, fileName, newFileName, originalFilename}` |
| `POST` | `/common/uploads` | 多文件上传，返回逗号分隔的 urls、fileNames 等 |
| `GET` | `/common/download` | 通用文件下载 |
| `GET` | `/common/download/resource` | 本地资源文件下载 |

**核心工具类**：`FileUploadUtils`（`fjtcmd-hub-common` 模块）
- 默认最大文件大小：**50MB**
- 默认最大文件名长度：**100 字符**
- 文件命名规则：日期路径 + 原文件名 + 序列号（如 `2026/06/09/filename_1.ext`）
- 存储路径：`uploadPath/upload/`
- 允许的文件扩展名：`bmp, gif, jpg, jpeg, png, doc, docx, xls, xlsx, ppt, pptx, html, htm, txt, rar, zip, gz, bz2, mp4, avi, rmvb, pdf`

**配置**：
```yaml
spring.servlet.multipart:
  max-file-size: 10MB
  max-request-size: 20MB
ruoyi.profile: /home/workspaces/com/ztq/tcmd/fjtcmd-hub/uploadPath
```
资源映射：`/profile/**` → `file:{profile}/`

### 前端上传组件

| 组件 | 路径 | 默认上传地址 |
|------|------|------------|
| `<file-upload>` | `src/components/FileUpload/index.vue` | `/common/upload` |
| `<image-upload>` | `src/components/ImageUpload/index.vue` | `/common/upload` |

**对接方式**：
- 前端组件直接调用 `/common/upload` 接口，上传成功后返回 `url` 字段
- 业务表的 `image` / `file` 字段保存的是 URL 字符串（相对路径，如 `/profile/upload/2026/06/09/image.jpg`）
- 代码生成器在 Vue 模板中，根据字段 `htmlType` 自动渲染为对应组件：
  - `htmlType=imageUpload` → `<image-upload v-model="form.xxx"/>`
  - `htmlType=fileUpload` → `<file-upload v-model="form.xxx"/>`
- Domain 类中这些字段保持 `String` 类型（存储 URL）
