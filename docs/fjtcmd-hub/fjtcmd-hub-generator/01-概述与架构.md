# 01 - 概述与架构

## 模块定位

`fjtcmd-hub-generator` 是若依（RuoYi-Vue）框架的**代码生成模块**，核心能力是：通过读取数据库表结构，结合用户配置的生成参数，利用 Velocity 模板引擎自动生成前后端 CRUD 代码。

生成的代码包括：
- **后端**：Domain 实体类、Mapper 接口、Mapper XML、Service 接口、Service 实现类、Controller
- **前端**：Vue 3 列表页面、API 接口文件、TypeScript 类型定义
- **其他**：菜单权限 SQL 脚本

## 项目结构

```
fjtcmd-hub-generator/
├── pom.xml                                    # Maven 模块描述
├── src/main/resources/
│   ├── generator.yml                          # 代码生成默认配置
│   ├── mapper/generator/
│   │   ├── GenTableMapper.xml                 # 表元数据 SQL
│   │   └── GenTableColumnMapper.xml           # 字段元数据 SQL
│   └── vm/                                    # Velocity 模板目录
│       ├── java/                              #   Java 后端模板（6个）
│       ├── xml/                               #   MyBatis XML 模板（1个）
│       ├── sql/                               #   菜单 SQL 模板（1个）
│       ├── js/                                #   JavaScript API 模板（1个）
│       ├── ts/                                #   TypeScript 模板（3个）
│       ├── vue/                               #   Vue3 默认模板（3个）
│       ├── vue/v3/                            #   Vue3 Element Plus 模板（3个）
│       └── vue/v3ts/                          #   Vue3 TypeScript 模板（3个）
└── src/main/java/com/ruoyi/generator/
    ├── config/
    │   └── GenConfig.java                     #   读取 generator.yml 配置
    ├── controller/
    │   └── GenController.java                 #   REST API 入口
    ├── domain/
    │   ├── GenTable.java                      #   业务表实体
    │   └── GenTableColumn.java                #   业务表字段实体
    ├── mapper/
    │   ├── GenTableMapper.java                #   表数据层
    │   └── GenTableColumnMapper.java          #   字段数据层
    ├── service/
    │   ├── IGenTableService.java              #   表服务接口
    │   ├── IGenTableColumnService.java        #   字段服务接口
    │   ├── GenTableServiceImpl.java           #   表服务实现
    │   └── GenTableColumnServiceImpl.java     #   字段服务实现
    └── util/
        ├── GenUtils.java                      #   代码生成工具类（类型映射、字段初始化）
        ├── VelocityInitializer.java           #   Velocity 引擎初始化
        └── VelocityUtils.java                 #   Velocity 模板变量构建工具
```

## 依赖关系

```xml
<!-- fjtcmd-hub-generator 的依赖 -->
org.apache.velocity:velocity-engine-core    # Velocity 模板引擎
com.fjtcmd.hub:fjtcmd-hub-common                       # 通用工具类、注解、基础类
com.alibaba:druid-spring-boot-4-starter      # Druid（用于执行 CREATE TABLE 语句）
```

- 依赖 `fjtcmd-hub-common`，间接获得 Spring、MyBatis、FastJSON2、Druid 等能力
- 独立于 `fjtcmd-hub-system` 业务模块，可作为可选模块启用或关闭

## REST API 一览

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| `GET` | `/tool/gen/list` | `tool:gen:list` | 查询已导入的代码生成列表 |
| `GET` | `/tool/gen/db/list` | `tool:gen:list` | 查询数据库表列表（未导入的） |
| `GET` | `/tool/gen/{tableId}` | `tool:gen:query` | 获取代码生成详细信息 |
| `GET` | `/tool/gen/column/{tableId}` | `tool:gen:list` | 查询表字段列表 |
| `POST` | `/tool/gen/importTable` | `tool:gen:import` | 导入表结构到代码生成器 |
| `POST` | `/tool/gen/createTable` | `admin` 角色 | 通过 SQL 创建表并导入 |
| `PUT` | `/tool/gen` | `tool:gen:edit` | 修改代码生成配置 |
| `DELETE` | `/tool/gen/{tableIds}` | `tool:gen:remove` | 删除代码生成记录 |
| `GET` | `/tool/gen/preview/{tableId}` | `tool:gen:preview` | 预览生成代码 |
| `GET` | `/tool/gen/download/{tableName}` | `tool:gen:code` | 下载代码（ZIP） |
| `GET` | `/tool/gen/genCode/{tableName}` | `tool:gen:code` | 生成到自定义路径 |
| `GET` | `/tool/gen/synchDb/{tableName}` | `tool:gen:edit` | 同步数据库表结构变更 |
| `GET` | `/tool/gen/batchGenCode` | `tool:gen:code` | 批量生成代码（ZIP） |

## 数据流向概览

```
用户操作（前端 UI）
       │
       ▼
GenController (REST API)
       │
       ├──→ GenTableService    ←→ GenTableMapper     ←→ MySQL (gen_table + information_schema)
       ├──→ GenTableColumnService ←→ GenTableColumnMapper ←→ MySQL (gen_table_column + information_schema)
       └──→ VelocityUtils + VelocityInitializer + GenUtils
                                    │
                                    ▼
                              *.vm 模板文件
                                    │
                                    ▼
                              渲染后的代码（预览/下载/写入文件）
```
