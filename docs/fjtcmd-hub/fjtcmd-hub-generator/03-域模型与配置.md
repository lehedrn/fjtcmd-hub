# 03 - 域模型与配置

## 3.1 GenTable — 代码生成业务表

**对应数据库表**：`gen_table`

| 字段 | 类型 | 说明 |
|------|------|------|
| tableId | Long | 编号（主键，自增） |
| tableName | String | 表名称（如 `sys_user`） |
| tableComment | String | 表描述（如 `用户信息表`） |
| subTableName | String | 关联子表的表名（主子表模式） |
| subTableFkName | String | 本表关联子表的外键名 |
| className | String | 实体类名（首字母大写，如 `SysUser`） |
| tplCategory | String | 使用的模板：`crud` / `tree` / `sub` |
| tplWebType | String | 前端模板类型：`element-plus` / `element-plus-typescript` |
| packageName | String | 生成包路径（如 `com.fjtcmd.hub.system`） |
| moduleName | String | 生成模块名（如 `system`） |
| businessName | String | 生成业务名（如 `user`） |
| functionName | String | 生成功能名（如 `用户信息`） |
| functionAuthor | String | 生成功能作者 |
| formColNum | Integer | 表单布局：1=单列, 2=双列, 3=三列 |
| genType | String | 生成代码方式：`0`=zip压缩包, `1`=自定义路径 |
| genPath | String | 生成路径（不填默认项目路径） |
| options | String | 其它生成选项（JSON 格式） |
| createBy | String | 创建者 |
| createTime | Date | 创建时间 |
| updateBy | String | 更新者 |
| updateTime | Date | 更新时间 |
| remark | String | 备注 |

### 关联字段（非持久化）

| 字段 | 类型 | 说明 |
|------|------|------|
| pkColumn | GenTableColumn | 主键列信息对象 |
| subTable | GenTable | 子表信息对象 |
| columns | List<GenTableColumn> | 表列信息列表 |
| treeCode | String | 树编码字段名 |
| treeParentCode | String | 树父编码字段名 |
| treeName | String | 树名称字段 |
| parentMenuId | Long | 上级菜单 ID |
| parentMenuName | String | 上级菜单名称 |
| isView | boolean | 是否生成详情页 |

### 常用判断方法

```java
isCrud()    // tplCategory == "crud"
isTree()    // tplCategory == "tree"
isSub()     // tplCategory == "sub"
isSuperColumn(javaField)  // 是否属于基类字段（不需要在 domain 中生成）
```

## 3.2 GenTableColumn — 代码生成业务字段表

**对应数据库表**：`gen_table_column`

| 字段 | 类型 | 说明 |
|------|------|------|
| columnId | Long | 编号（主键，自增） |
| tableId | Long | 归属表编号 |
| columnName | String | 列名称（数据库字段名，如 `user_name`） |
| columnComment | String | 列描述（如 `用户名称`） |
| columnType | String | 列类型（如 `varchar(50)`） |
| javaType | String | JAVA类型（`String` / `Date` / `Long` / `Integer` / `BigDecimal`） |
| javaField | String | JAVA字段名（驼峰，如 `userName`） |
| isPk | String | 是否主键（`1`=是） |
| isIncrement | String | 是否自增（`1`=是） |
| isRequired | String | 是否必填（`1`=是） |
| isInsert | String | 是否为插入字段（`1`=是） |
| isEdit | String | 是否编辑字段（`1`=是） |
| isList | String | 是否列表字段（`1`=是） |
| isQuery | String | 是否查询字段（`1`=是） |
| queryType | String | 查询方式：`EQ` / `NE` / `GT` / `GTE` / `LT` / `LTE` / `LIKE` / `BETWEEN` |
| htmlType | String | 显示类型：`input` / `textarea` / `select` / `radio` / `checkbox` / `datetime` / `imageUpload` / `fileUpload` / `editor` |
| dictType | String | 字典类型 |
| sort | Integer | 排序（ordinal_position） |
| createBy | String | 创建者 |
| createTime | Date | 创建时间 |
| updateBy | String | 更新者 |
| updateTime | Date | 更新时间 |

### 常用判断方法

```java
isPk()        // isPk == "1"
isIncrement() // isIncrement == "1"
isRequired()  // isRequired == "1"
isInsert()    // isInsert == "1"
isEdit()      // isEdit == "1"
isList()      // isList == "1"
isQuery()     // isQuery == "1"
isSuperColumn()       // 是否基类字段（createBy, createTime, updateBy, updateTime, remark, parentId, orderNum, ancestors）
isUsableColumn()      // 是否可用列（parentId, orderNum, remark — 页面需要但不在 domain 中生成）
getCapJavaField()     // 首字母大写的 javaField
readConverterExp()    // 从注释中解析转换器表达式（用于 @Excel 注解）
```

## 3.3 GenConfig — 代码生成配置

**配置来源**：`classpath:generator.yml`

```yaml
gen:
  author: ruoyi              # 默认作者
  packageName: com.fjtcmd.hub.system  # 默认生成包路径
  autoRemovePre: false       # 自动去除表前缀
  tablePrefix: sys_          # 表前缀（多个用逗号分隔）
  allowOverwrite: false      # 是否允许生成文件覆盖到本地
```

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| author | String | ruoyi | 生成代码中的作者署名 |
| packageName | String | com.fjtcmd.hub.system | 生成代码的 Java 包前缀 |
| autoRemovePre | boolean | false | 导入表时是否自动去除表名前缀 |
| tablePrefix | String | sys_ | 要去除的表前缀列表（逗号分隔） |
| allowOverwrite | boolean | false | 是否允许生成代码覆盖本地文件 |

**注意**：配置值通过 `@Value` 注入到静态字段，所有模块共享同一份配置。

## 3.5 数据库表结构

### gen_table（代码生成业务表）

```sql
create table gen_table (
  table_id          bigint(20)      not null auto_increment    comment '编号',
  table_name        varchar(200)    default ''                 comment '表名称',
  table_comment     varchar(500)    default ''                 comment '表描述',
  sub_table_name    varchar(64)     default null               comment '关联子表的表名',
  sub_table_fk_name varchar(64)     default null               comment '子表关联的外键名',
  class_name        varchar(100)    default ''                 comment '实体类名称',
  tpl_category      varchar(200)    default 'crud'             comment '模板类型',
  tpl_web_type      varchar(30)     default ''                 comment '前端模板类型',
  package_name      varchar(100)                               comment '生成包路径',
  module_name       varchar(30)                                comment '生成模块名',
  business_name     varchar(30)                                comment '生成业务名',
  function_name     varchar(50)                                comment '生成功能名',
  function_author   varchar(50)                                comment '生成功能作者',
  form_col_num      int(1)          default 1                  comment '表单列数',
  gen_type          char(1)         default '0'                comment '生成方式',
  gen_path          varchar(200)    default '/'                comment '生成路径',
  options           varchar(1000)                              comment '其它生成选项',
  create_by         varchar(64)     default ''                 comment '创建者',
  create_time       datetime                                   comment '创建时间',
  update_by         varchar(64)     default ''                 comment '更新者',
  update_time       datetime                                   comment '更新时间',
  remark            varchar(500)    default null               comment '备注',
  primary key (table_id)
) engine=innodb auto_increment=1 comment = '代码生成业务表';
```

### gen_table_column（代码生成业务表字段）

```sql
create table gen_table_column (
  column_id         bigint(20)      not null auto_increment    comment '编号',
  table_id          bigint(20)                                 comment '归属表编号',
  column_name       varchar(200)                               comment '列名称',
  column_comment    varchar(500)                               comment '列描述',
  column_type       varchar(100)                               comment '列类型',
  java_type         varchar(500)                               comment 'JAVA类型',
  java_field        varchar(200)                               comment 'JAVA字段名',
  is_pk             char(1)                                    comment '是否主键',
  is_increment      char(1)                                    comment '是否自增',
  is_required       char(1)                                    comment '是否必填',
  is_insert         char(1)                                    comment '是否为插入字段',
  is_edit           char(1)                                    comment '是否编辑字段',
  is_list           char(1)                                    comment '是否列表字段',
  is_query          char(1)                                    comment '是否查询字段',
  query_type        varchar(200)    default 'EQ'               comment '查询方式',
  html_type         varchar(200)                               comment '显示类型',
  dict_type         varchar(200)    default ''                 comment '字典类型',
  sort              int                                        comment '排序',
  create_by         varchar(64)     default ''                 comment '创建者',
  create_time       datetime                                   comment '创建时间',
  update_by         varchar(64)     default ''                 comment '更新者',
  update_time       datetime                                   comment '更新时间',
  primary key (column_id)
) engine=innodb auto_increment=1 comment = '代码生成业务表字段';
```
