# fjtcmd-hub-ui

体彩门店智慧互动信息管理系统 - 前端

## 技术栈

- Vue 3 + TypeScript
- Vite 6
- Element Plus
- Pinia 状态管理
- Vue Router 4
- Axios
- ECharts
- VueQuill

## 开发

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 生产环境构建
pnpm build:prod

# 预发布环境构建
pnpm build:stage
```

## 基于

本项目基于 [RuoYi-Vue](https://gitee.com/y_project/RuoYi-Vue) v3.9.2 二次开发。
